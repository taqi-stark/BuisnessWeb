# Ali Taqi — Python Backend Engineer Portfolio

Personal portfolio web application showcasing backend architecture, API designs, distributed systems, and real-time platforms.

## 🚀 Tech Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **UI Components:** Radix UI primitives, Lucide Icons, Framer Motion
- **3D Graphics:** Three.js / React Three Fiber
- **Testing:** Vitest, Testing Library

## 🛠️ Getting Started

### Install dependencies:

```bash
npm install
# or
bun install
```

### Development server:

```bash
npm run dev
# or
bun dev
```

### Run tests:

```bash
npm test
# or
bun test
```

### Production build:

```bash
npm run build
```
